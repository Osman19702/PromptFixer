## PromptFixer 0.1.0 — Windows x64 installer

Lints, scores and rewrites LLM prompts with a built-in local model (Qwen3 4B); nothing you type leaves your machine. Cloud providers (Anthropic, OpenAI, Gemini, OpenRouter, Ollama) are optional.

**Download:** `PromptFixer-0.1.0-win-x64.exe` (~355 MB). Windows 10/11, 64-bit. The model (2.5 GB, or the 1 GB "lite" tier) is downloaded on first run into `%USERPROFILE%\.promptfixer\models`.

**Verify:** installer SHA-256 `4f49a75fa3b01cbf98cee56100e2afdc14b42b56b1eef3853e47afc010194c2e` (`SHA256SUMS.txt` is attached). PowerShell: `(Get-FileHash .\PromptFixer-0.1.0-win-x64.exe).Hash.ToLower()` must equal it.

**Not code-signed yet:** Windows shows "Windows protected your PC" → *More info* → *Run anyway*. Compare the hash first if in doubt. Full guide: `docs/INSTALL.md`.

Why ~355 MB: the installer ships prebuilt CPU, Vulkan and CUDA llama.cpp backends so the right one is picked at runtime. The `.blockmap` is only for future differential updates.
