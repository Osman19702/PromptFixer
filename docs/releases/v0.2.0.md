## PromptFixer 0.2.0 — Windows x64 installer

Lints, scores and rewrites LLM prompts with a built-in local model (Qwen3 4B); nothing you type leaves your machine. Cloud providers (Anthropic, OpenAI, Gemini, OpenRouter, Ollama) are optional.

**New in 0.2.0: fix again with your marks.** Select any passage of a rewrite and mark it *Keep it — I loved it* or *Change it — I didn't like it*, then press *Fix again with my marks*. The model revises its own rewrite instead of starting over: what you kept comes back word for word, what you disliked is reworded, and the result is still scored against the prompt you wrote. A rewrite that ignores a mark is retried once, and you are told when a mark was not followed. For scripts, `POST /api/fix` takes the marks as an optional `feedback` field; requests without it behave as in 0.1.0. Also fixed: saving to the library on Windows no longer fails when another program has `library.json` open at that instant. Everything else is in [CHANGELOG.md](../../CHANGELOG.md#020---2026-09-17).

**Download:** `PromptFixer-0.2.0-win-x64.exe` (`TBD` MiB). Windows 10/11, 64-bit. The model (2.5 GB, or the 1 GB "lite" tier) is downloaded on first run into `%USERPROFILE%\.promptfixer\models`.

**Upgrading from 0.1.0:** run the new installer over the old one. Your library (`%APPDATA%\PromptFixer\data\library.json`) and the downloaded model are outside the install folder and stay as they are.

**Verify:** installer SHA-256 `TBD` (`SHA256SUMS.txt` is attached). PowerShell: `(Get-FileHash .\PromptFixer-0.2.0-win-x64.exe).Hash.ToLower()` must equal it.

**Not code-signed yet:** Windows shows "Windows protected your PC" → *More info* → *Run anyway*. Compare the hash first if in doubt. Full guide: `docs/INSTALL.md`.

Why the installer is this large: it ships prebuilt CPU, Vulkan and CUDA llama.cpp backends so the right one is picked at runtime. The `.blockmap` is only for future differential updates.
