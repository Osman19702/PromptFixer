## PromptFixer 0.3.0 — Windows x64 installer

Lints, scores and rewrites LLM prompts with a built-in local model (Qwen3 4B); nothing you type leaves your machine. Cloud providers (Anthropic, OpenAI, Gemini, OpenRouter, Ollama) are optional.

**New in 0.3.0: the waiting is over, and the privacy claim is now a test.** The rewrite appears in the Fixed tab as the model writes it, instead of a spinner for half a minute or more. A line under the spinner names which wait you are in — queued behind another job, loading the model, writing, or the second attempt after a failed quality check, which used to double the wait in silence. An over-long prompt is flagged in the editor as you type rather than refused once the model has loaded. Loading shows a real progress bar and the download shows its speed and time remaining. The model is released after fifteen minutes of doing nothing, or at once with *Release model*, so the app can sit open beside everything else on an 8 GB laptop; you can also delete a downloaded model from inside the app, and a download that will not fit is refused in under a second instead of failing part-way. The running version is shown beside the app name, and every saved result now records the build that produced it.

**"Nothing leaves your machine" is checked on every build.** It used to be a person unplugging a network cable. A full session — score, fix, save, export, and the same session again in a browser — now runs under a watcher that records any connection to an address that is not this machine, and the build fails if it records one. [docs/PRIVACY.md](../PRIVACY.md) names every host the app can reach and when, where your prompts are stored, and is explicit about what the test cannot cover. Related: the app no longer fetches and compiles its model engine from source when no ready-made one is found, which meant downloading code without asking.

Everything else is in [CHANGELOG.md](../../CHANGELOG.md#030---2026-09-21).

**Download:** `PromptFixer-0.3.0-win-x64.exe` (`TBD` MiB). Windows 10/11, 64-bit. The model (2.5 GB, or the 1 GB "lite" tier) is downloaded on first run into `%USERPROFILE%\.promptfixer\models`.

**Upgrading from 0.2.0:** run the new installer over the old one. Your library (`%APPDATA%\PromptFixer\data\library.json`) and the downloaded model are outside the install folder and stay as they are. Entries saved before this version show as *version unknown* in the library, because the build that produced them was never recorded — they are not stamped with this one, so an old score can still be told apart from a defect.

**Verify:** installer SHA-256 `TBD` (`SHA256SUMS.txt` is attached). PowerShell: `(Get-FileHash .\PromptFixer-0.3.0-win-x64.exe).Hash.ToLower()` must equal it.

**Not code-signed yet:** Windows shows "Windows protected your PC" → *More info* → *Run anyway*. Compare the hash first if in doubt. Full guide: `docs/INSTALL.md`.

Why the installer is this large: it ships prebuilt CPU, Vulkan and CUDA llama.cpp backends so the right one is picked at runtime. The `.blockmap` is only for future differential updates.
